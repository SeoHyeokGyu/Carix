# Carix UI/UX Layout Design Specification

이 문서는 Carix 플랫폼의 비주얼 테마, 대시보드 구조, 주요 컴포넌트 레이아웃 및 온보딩 위저드 흐름을 정의합니다. 프리미엄 느낌의 다크 모드와 고대비 데이터 시각화를 지향합니다.

---

## 1. 비주얼 테마 및 디자인 시스템 토큰

### 1.1 컬러 팔레트 (Color Palette - Tailwind/Vanilla CSS 호환)
*   **배경 (Background):** `Slate 950` (`#020617`) - 심해의 어둠을 모티브로 한 매우 깊은 블루 블랙.
*   **표면 (Surface/Card):** `Slate 900` (`#0f172a`)에 투명도 80% 적용 + Subtle Border (`Slate 800`, `#1e293b`).
*   **주요 텍스트 (Primary Text):** `Slate 50` (`#f8fafc`).
*   **강조 색상 (Accent Colors):**
    *   **상승 / 긍정 (Positive):** `Emerald 400` (`#34d399`) - 성장 신호.
    *   **경고 / 하락 (Warning):** `Amber 400` (`#fbbf24`) - 물가 상승 혹은 지수 감소 경고.
    *   **위험 (Danger):** `Rose 400` (`#fb7185`) - 급격한 가치 하락 및 주의 신호.
    *   **정보 / 기준 (Info):** `Indigo 400` (`#818cf8`) - 동료집단 기준 지표.

### 1.2 서체 (Typography)
*   **숫자 및 지표:** `Outfit` 또는 `Inter` (Google Fonts) - 가독성이 높은 기하학적 폰트 적용.
*   **본문 텍스트:** `Pretendard` 또는 `Inter` - 글자 간격 자간 `-0.02em` 적용하여 정밀하고 단단한 분위기 연출.

## 2. 온보딩 위저드 흐름 (Onboarding Flow)

온보딩은 한 번에 입력하지 않고, 진행 상태가 상단 인디케이터에 나타나는 **단계식 전환(Progressive Wizard)**으로 구성합니다. 화면 오른쪽 상단에는 항상 "자동 저장됨 (Auto-saved)"이라는 희미한 미세 애니메이션 상태 텍스트를 노출합니다.

```text
[ 1. 기본 프로필 ] ───▶ [ 2. 소득 관리 ] ───▶ [ 3. 월 소비 비중 ] ───▶ [ 4. 보유 스킬 ]
```

*   **Step 1: 기본 프로필:** 주 직무(드롭다운), 총 경력(숫자 입력), 희망 근무 지역, 고용 형태.
*   **Step 2: 소득 관리:** 세전 연봉 슬라이더/인풋 및 월 실수령액(선택적) 기재 필드.
*   **Step 3: 소비 비중:** 6대 소비 카테고리별 슬라이더(총합이 100%가 되도록 조정하거나, 월별 절대 금액 입력 시 백분율로 자동 계산하여 도넛 차트 시각화 제공).
*   **Step 4: 보유 스킬:** 자동완성 검색 기능이 제공되는 태그 입력 창. 추가 시 하단에 '실무 기간(개월)'과 '마지막 사용일' 입력란 활성화.

## 3. 대시보드 메인 레이아웃 구조 (Dashboard Layout)

대시보드 메인은 크게 **상단 헤더(기준 정보)** ➡️ **중단 지표 카드(핵심 성과)** ➡️ **하단 차트 및 시뮬레이터(상세 분석)** 영역의 Grid 레이아웃으로 화면을 분할합니다.

```text
┌────────────────────────────────────────────────────────────────────────┐
│ Carix Logo                                         [ user@example.com ] │
├────────────────────────────────────────────────────────────────────────┤
│ (헤더) 5년차 백엔드 개발자 | 서울 강남 | 정규직      [ 기준일: 2026-07-01 ] │
├────────────────────────────────────────────────────────────────────────┤
│  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐  │
│  │ 1. 구매력 지수    │  │ 2. 시장가치 지수  │  │ 3. 결정 신호     │  │
│  │   94.2  (▼1.2)   │  │   117.5 (▲3.8)   │  │    이직 탐색     │  │
│  │  [ 카테고리별CPI ] │  │  [ 스킬 수요율 ]  │  │  [ 근거 펼치기 ] │  │
│  └──────────────────┘  └──────────────────┘  └──────────────────┘  │
├────────────────────────────────────────────────────────────────────────┤
│  ┌────────────────────────────────────────┐  ┌───────────────────────┐  │
│  │ [Tab: 소득vs물가 / 스킬수요 / 연봉분포]  │  │ [ 12개월 시뮬레이터 ] │  │
│  │                                        │  │                       │  │
│  │        [ 차트 / 데이터 렌더링 ]         │  │  - 예상인상률   [3.5%] │  │
│  │                                        │  │  - 이직목표액   [72M ] │  │
│  │                                        │  │  - 이직비용     [ 3M ] │  │
│  │                                        │  │                       │  │
│  │                                        │  │  [ 잔류 vs 이직 차트 ]│  │
│  └────────────────────────────────────────┘  └───────────────────────┘  │
└────────────────────────────────────────────────────────────────────────┘
```

### 3.1 3대 핵심 지표 카드 상세 레이아웃

#### Card 1: 실질 구매력 지수 (Purchasing Power Index)
*   **UI 구성:** 좌측 상단에 `94.2`를 크게 표기하고 우측에 하락 화살표(`▼ 1.2%`)를 경고 색상(`Amber`)으로 표기.
*   **미니 비주얼:** 카드 하단에 6대 카테고리 중 물가 상승 타격을 가장 크게 준 1위 품목(예: "교통비 부담률 최대 상승")을 요약 뱃지로 제공.

#### Card 2: 스킬 시장가치 지수 (Market Value Index)
*   **UI 구성:** 좌측 상단에 `117.5`를 표기하고 우측에 상승 화살표(`▲ 3.8%`)를 성장 색상(`Emerald`)으로 표기.
*   **미니 비주얼:** 최근 3개월간 채용 공고 수요 비중이 급상승한 스킬 뱃지 표시 (예: `Spring Boot`, `TypeScript`).

#### Card 3: 결정 신호 (Decision Signal)
*   **UI 구성:** 배경색에 은은한 앰버/에메랄드 그라데이션이 들어간 대형 뱃지(예: `이직 탐색`) 배치.
*   **아코디언(Accordion):** 클릭 시 하단으로 드롭다운이 열리며 판정 룰 목록과 근거 텍스트("보유 스킬 수요는 늘었으나 연봉은 시장 대비 18% 낮음")가 슬라이드 애니메이션으로 열림.

## 4. 데이터 시각화 컴포넌트

### 4.1 소득 vs 물가 추세선 (Line Chart)
*   **X축:** 월별 시간 흐름 (최근 12개월)
*   **Y축:** 금액(원화) 및 지수
*   **차트 요소:**
    *   **실선 A (Indigo):** 명목 소득(매월 실제 받은 실수령액 또는 연동액)
    *   **점선 B (Amber):** 개인 소비 구조에 맞춘 물가 누적 변화율 곡선
    *   **음영 영역:** A 곡선이 B 곡선 아래로 내려갈 때, 두 선 사이의 틈을 희미한 빨간색 그라데이션 음영으로 칠해 **'구매력 손실'** 구간임을 직관적으로 인지시킴.

### 4.2 동료집단 연봉 분포 막대 (Range Bar / Box Plot)
*   **디자인:** 가로 선으로 된 스펙트럼 바 위에 최소값, 25%, 중앙값(50%), 75%, 최대값을 도식화.
*   **사용자 핀:** 가로 바 상단에 현재 사용자의 연봉을 나타내는 세로 핀(Pin) 지시선과 사용자 프로필 말풍선 노출.
    *   *예: "내 연봉은 동료집단 중 상위 65% 위치에 있습니다."*
