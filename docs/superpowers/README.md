# superpowers/ — 동결(frozen) 원본

이 디렉터리는 사양 주도(spec-driven) 워크플로우로 최초 작성된 설계 산출물의 **원본**이다.
**동결 상태로 보존**하며 더 이상 갱신하지 않는다.

정본(canonical)은 [`docs/specs/`](../specs/)와 [`docs/plans/`](../plans/)이며, 앞으로의
수정은 정본에만 반영한다. 문서 탐색은 [문서 맵](../README.md)에서 시작한다.

- [`specs/`](specs/) — 설계 문서 원본 (동결)
- [`plans/`](plans/) — 계획 문서 원본 (동결)
