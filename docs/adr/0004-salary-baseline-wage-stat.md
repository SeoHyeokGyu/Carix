# 0004. 연봉 격차 기준선을 공고 공개연봉 → 공식 임금통계

- 상태: 채택
- 날짜: 2026-07-15 (계보 결정으로 2026-07-19 확정)

## 맥락

초기 설계는 연봉 격차·결정 신호의 기준선으로 채용공고의 공개연봉 중앙값을 썼다.
그러나 대부분의 공고가 "회사 내규에 따름"으로 연봉을 공개하지 않아 결측률이 매우
높고, 표본 편향(공공 플랫폼 중심)이 크다.

## 결정

연봉 격차 판정 기준선을 **공식 임금통계**(임금직무정보시스템 또는 KOSIS 직종별
임금)로 교체한다. 공고 공개연봉 분포는 표본이 충분할 때 **참고로만 병기**하고 지수·
신호 입력에서 제외한다.

- 연봉 격차 = (공식 임금통계 중앙값 − 사용자 세전연봉) ÷ 사용자 세전연봉.
- 사용자가 시장 중앙값보다 낮을 때 양수(결정표 `SalaryGapRatio ≥ 0.15` 규약과 동일).

## 대안

- **공개연봉 유지** — 결측률·편향으로 신뢰 가능한 기준선을 만들기 어렵다.

## 결과

- 스킬 수요 원천도 고용24 단일 → 고용24 + 사람인 2개로 확장(커버리지 보완),
  임금통계까지 총 4원천. RawIngest 원문 보존, 원천 간 dedup, 원천별 집계 후 표본수
  가중 결합.
- `wage_stat_observation` 테이블 신설(직종×경력구간×지역 중앙값, 임금 정의,
  `stat_vintage`).
- **선행 검증 차단 조건:** 임금통계 API 제공 여부와 사람인 이용약관은 구현 착수 전
  검증해야 한다. 검증 실패 시 어댑터 비활성화로 흡수하되, 임금통계 미확보 시 연봉
  격차·결정 신호 일부가 무력화된다.
