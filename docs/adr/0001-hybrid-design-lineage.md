# 0001. 설계 계보 하이브리드 (제품 7/18 · 데이터 7/15)

- 상태: 채택
- 날짜: 2026-07-19

## 맥락

[파이프라인 재설계(2026-07-15)](../specs/data-architecture.md)가
[MVP 설계(2026-07-12)](../specs/mvp-requirements.md) 전체 대체를
선언했으나, 이후 2026-07-18 상세 문서군(API·DB·UI·워크플로우)이 구 MVP 라인을
따르며 계보가 두 갈래로 분기했다. 재설계는 제품을 포트폴리오·학습용으로 축소
(본인+데모 계정, 매직링크 제거)하고 지수를 개명했으나, 7/18 이후 작업 전부가
초대 베타 제품 라인 기준이었다.

## 결정

계보를 하이브리드로 정리한다.

- **제품 기능: 2026-07-18 라인 유지** — 초대 베타(10~30명), 매직링크 로그인,
  온보딩 5단계, 이력 관리, 계정 삭제. 재설계의 제품 축소·지수 개명은 미채택.
- **데이터 아키텍처: 2026-07-15 재설계 채택** — 원천 4개, 임금통계 기준선,
  RawIngest 원문 보존, 원천 간 dedup, 원천별 집계 후 표본수 가중 결합.

## 대안

- **A. 7/18 라인 전면 유지, 재설계 폐기** — 데이터 리스크(고용24 커버리지, 공개연봉
  결측) 미해결.
- **B. 7/15 재설계 전면 채택** — 인증·온보딩·삭제 등 7/18 산출물 대규모 재작업.

## 결과

- 7/15 문서 상단에 "부분 채택" 상태 표기, 유효(데이터)/역사(제품) 절 구분.
- 7/12 MVP 문서에 데이터 아키텍처 절 대체 배너 추가.
- 기준 문서: 제품은 MVP 설계 + 기능 분해, 데이터는 재설계. 충돌 시 이 ADR과
  기능 분해 §6.1을 따른다.
