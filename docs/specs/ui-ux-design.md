# Carix UI/UX Layout Design Specification

이 문서는 Carix 플랫폼의 비주얼 테마, 대시보드 구조, 주요 컴포넌트 레이아웃 및 온보딩 위저드 흐름을 정의합니다. 프리미엄 느낌의 다크 모드와 고대비 데이터 시각화를 지향합니다.

---

## 1. 비주얼 테마 및 디자인 시스템 토큰

### 1.1 컬러 팔레트 (Color Palette - 듀얼 모드 지원 & WCAG AA 접근성 준수)
*   **라이트 모드 (Light Mode):**
    *   **배경 (Background):** 매우 연한 블루그레이 배경 (`#F3F4F6`) - 캐주얼 리포트 느낌의 산뜻한 배경.
    *   **표면 (Surface/Card):** 순백색 카드 (`#FFFFFF`) 및 연한 보더 그레이 (`#E5E7EB`).
    *   **주요 텍스트 (Primary Text):** 텍스트 다크 그레이 (`#1F2937`).
    *   **브랜드/정보 컬러 (Primary/Info):** 인디고 브랜드 컬러 (`#4F46E5`).
    *   **상승 / 긍정 (Positive):** 에메랄드 그린 (`#047857`) - 흰색 배경 명도 대비(5.29:1)를 만족하는 가독성 그린.
    *   **경고 / 하락 (Warning):** 오렌지 다크 (`#c2410c`) - 흰색 배경 명도 대비(4.84:1)를 만족하는 가독성 오렌지.
    *   **위험 (Danger):** 빨간색 (`#EF4444`).
    *   **행동 권장 (Action):** 바이올렛 (`#6d28d9`) - 흰색 배경 명도 대비(7.10:1)를 만족. 결정 신호 `협상 검토` 에 쓴다.
*   **다크 모드 (Dark Mode):**
    *   **배경 (Background):** 부드러운 다크 그레이 배경 (`#111827`) - 은은하고 눈이 편안한 깊은 그레이.
    *   **표면 (Surface/Card):** 매끄러운 다크 카드 (`#1F2937`) 및 다크 보더 그레이 (`#374151`).
    *   **주요 텍스트 (Primary Text):** 다크 텍스트 (`#F9FAFB`).
    *   **브랜드/정보 컬러 (Primary/Info):** 연한 인디고 (`#818CF8`).
    *   **상승 / 긍정 (Positive):** 네온 그린 (`#10B981`) - 성장 신호.
    *   **경고 / 하락 (Warning):** 오렌지 (`#F97316`) - 경고 신호.
    *   **위험 (Danger):** 연한 빨간색 (`#F87171`).
    *   **행동 권장 (Action):** 연한 바이올렛 (`#a78bfa`) - 다크 카드 명도 대비(5.39:1)를 만족. 결정 신호 `협상 검토` 에 쓴다.

### 1.2 서체 (Typography)
*   **숫자 및 지표:** `Outfit` 또는 `Inter` (Google Fonts) - 가독성이 높은 기하학적 폰트 적용.
*   **본문 텍스트:** `Pretendard` 또는 `Inter` - 글자 간격 자간 `-0.02em` 적용하여 정밀하고 단단한 분위기 연출.

### 1.3 스타일 및 레이아웃 지침 (Style & Layout Guidelines)
*   **Style & Tone:** 친근하고 캐주얼한 커리어 금융 리포트 스타일. 대화체 설명 중심이며, 복잡한 통계 수치나 세부 공식은 ❓ 마크 툴팁 뒤로 숨겨 첫인상을 깔끔하게 유도.
*   **Layout:** 복잡한 사이드바를 제거하고, 모바일에서는 **단일 컬럼 피드(Single-column Feed)**, 데스크톱/태블릿에서는 한눈에 보기 편한 **반응형 가로 그리드(Grid) 및 프로세스 플로우** 배치 채택.
*   **Visual Elements:** 카테고리별 직관적인 이모지 사용(💰, 📈, ⚖️, 🧭, 🔄, ✨) 및 딱딱한 수치 나열 대신 둥근 프로그레스 바 적용.

## 2. 온보딩 위저드 흐름 (Onboarding Flow)

온보딩은 한 번에 입력하지 않고, 진행 상태가 상단 인디케이터에 나타나는 **단계식 전환(Progressive Wizard)**으로 구성합니다. 화면 오른쪽 상단에는 저장 상태 텍스트를 노출합니다: 서버 저장 성공 시 "자동 저장됨 (Auto-saved)", 저장 중 "저장 중...", 재시도 실패 시 오류 배너로 전환하고 입력값은 화면에 보존합니다 (기능 분해 명세 US-O1 인수 조건과 동일).

```text
[ 1. 기본 프로필 ] ──▶ [ 2. 소득 관리 ] ──▶ [ 3. 월 소비 비중 ] ──▶ [ 4. 보유 스킬 ] ──▶ [ 5. 검토 ]
```

*   **Step 1: 기본 프로필:** 주 직무(드롭다운), 총 경력(숫자 입력), 희망 근무 지역, 고용 형태.
*   **Step 2: 소득 관리:** 세전 연봉 인풋 및 월 실수령액(선택적) 기재 필드. 사용자 입력 편의를 위해 **만원 단위**로 입력하며, 천 단위 콤마(`,`) 서식과 실시간 원화 환산(`= N원`)을 제공. 적용일 필드는 직관적인 **"연봉 적용 시작일"**로 표기.
*   **Step 3: 소비 비중:** 6대 소비 카테고리별 **월 절대 금액 입력** (백분율은 자동 계산해 도넛 차트로 시각화). % 직접 입력 방식은 사용하지 않는다 — 미입력 카테고리 감지와 기본 가중치 보완, 실수령액 대비 경고가 절대 금액을 전제하기 때문. 미입력 카테고리에는 `통계청 평균 기준` 뱃지를 즉시 표시.
*   **Step 4: 보유 스킬:** 자동완성 검색 기능이 제공되는 태그 입력 창. 추가 시 하단에 '실무 기간(개월)'과 '마지막 사용일' 입력란 활성화.
*   **Step 5: 검토:** 입력 요약, 기본값으로 대체된 항목, 계산 제한 사항을 확인 후 완료 제출. 항목별 `수정` 버튼으로 해당 단계 재진입 가능. 온보딩 완료(`COMPLETED`) 후 재진입 시 상단에 '온보딩 완료 상태' 알림 배너와 함께 **'온보딩 처음부터 다시 시작'** 및 **'대시보드로 돌아가기'** 버튼을 제공.

### 2.1 온보딩 재시작 흐름 (Onboarding Restart / Reset)
*   **진입점:**
    1. **검토 화면 (`/onboarding/review`):** 온보딩 완료 사용자에게 안내 배너 및 '온보딩 처음부터 다시 시작' 버튼 제공.
    2. **마이페이지 설정 (`/mypage/profile`):** '온보딩 재설정' 카드에서 '온보딩 처음부터 다시 시작' 액션 제공 (기존 입력 데이터가 삭제되지 않고 유지된다는 안내 포함).
    3. **대시보드 메인 (`/dashboard`):** 상단 헤더의 '온보딩 검토 및 재시작' 링크 및 상단 탭 '설정'을 통해 즉시 접근 가능.
*   **사용자 경험:** 재시작 시 온보딩 단계가 1단계(`PROFILE`)로 리셋되며, 기존에 등록된 프로필·소득·소비·스킬 데이터가 인풋에 그대로 보존되어 있어 필요한 부분만 손쉽게 수정하고 다음 단계로 진행할 수 있습니다.

## 3. 대시보드 메인 레이아웃 구조 (Dashboard Layout)

대시보드 메인은 **상단 헤더(기준 정보)** ➡️ **핵심 지표 카드(4종)** 두 영역으로 구성된 축소 레이아웃입니다. 정보 과부하를 줄이기 위해 추이 차트와 12개월 시뮬레이터는 아래 §3.2와 같이 독립 메뉴(추이 분석/시뮬레이터)로 분리했습니다.
네비게이션은 글로벌 GNB(`AppShell`)로 통일하여 좌측에 `Carix 로고`와 함께 `지표 | 이력 | 추이 분석 | 시뮬레이터 | 이력 관리` 5개 주 메뉴를 고정 배치하고, 우측에 `⚙️ 설정` 및 `테마 전환(🌙/☀️)` 유틸리티를 분리 배치했습니다. 이를 통해 사용자가 '설정' 페이지에 진입하더라도 상단 메인 메뉴가 사라지지 않고 항상 동일한 자리에 유지되어 언제든 즉시 분석 화면으로 복귀할 수 있습니다. §1.3의 "사이드바 제거" 원칙과 별개로, 상단 네비 자체는 항상 플랫하게 유지합니다.

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│ Carix Logo     [지표] [이력] [추이 분석] [시뮬레이터] [이력 관리]      [⚙️ 설정] [🌙] │
├───────────────────────────────────────────────────────────────────────────────┤
│ (헤더) 5년차 백엔드 개발자 | 서울 강남 | 정규직         [ 기준일: 2026-07-01 ] │
├───────────────────────────────────────────────────────────────────────────────┤
│  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐             │
│  │ 1. 구매력 지수    │  │ 2. 시장가치 지수  │  │ 3. 결정 신호     │             │
│  │   94.2  (▼1.2)   │  │   117.5 (▲3.8)   │  │    이직 탐색     │             │
│  │  [ 카테고리별CPI ] │  │  [ 스킬 수요율 ]  │  │  [ 근거 펼치기 ] │             │
│  └──────────────────┘  └──────────────────┘  └──────────────────┘             │
└───────────────────────────────────────────────────────────────────────────────┘
```

### 3.1 핵심 지표 카드 상세 레이아웃

#### Card 1: 실질 구매력 지수 (Purchasing Power Index)
*   **UI 구성:** 좌측 상단에 `94.2`를 크게 표기하고 우측에 하락 화살표(`▼ 1.2p`, 전월 대비 지수 포인트 차이)를 경고 색상(`Amber`)으로 표기.
*   **미니 비주얼:** 카드 하단에 6대 카테고리 중 물가 상승 타격을 가장 크게 준 1위 품목(예: "교통비 부담률 최대 상승")을 요약 뱃지로 제공.

#### Card 2: 스킬 시장가치 지수 (Market Value Index)
*   **UI 구성:** 좌측 상단에 `117.5`를 표기하고 우측에 상승 화살표(`▲ 3.8p`, 전월 대비 지수 포인트 차이)를 성장 색상(`Emerald`)으로 표기.
*   **미니 비주얼:** 최근 3개월간 채용 공고 수요 비중이 급상승한 스킬 뱃지 표시 (예: `Spring Boot`, `TypeScript`).

#### Card 3: 결정 신호 (Decision Signal)
*   **UI 구성:** 배경색에 은은한 앰버/에메랄드 그라데이션이 들어간 대형 뱃지(예: `이직 탐색`) 배치.
*   **아코디언(Accordion):** 클릭 시 하단으로 드롭다운이 열리며 판정 룰 목록과 근거 텍스트("보유 스킬 수요는 상승세, 공식 임금통계 중앙값 대비 연봉 격차 20%")가 슬라이드 애니메이션으로 열림.
*   **처방 블록(`스킬 보강 우선` 신호에만):** 아코디언 하단에 동료집단 수요율 상위 미보유 스킬 3개를 수요율과 함께 뱃지로 붙인다. 다섯 신호 중 이 신호만 다음 행동이 비어 있어 더한다 ([기능 명세 US-D6](functional-specification.md)). 표본 부족이면 목록을 비우고 `표본 부족` 을 표시한다.

#### Card 4: 개방창 지수 (Opening Window Index)
*   **UI 구성:** 좌측 상단에 `118.4`를 표기하고 우측에 전월 대비 지수 포인트 차이를 Card 1·2와 같은 규칙으로 표기. **100 초과가 구직자에게 유리한 방향**이므로 상승을 성장 색상(`Emerald`)으로 쓴다.
*   **미니 비주얼:** 중앙 모집기간(예: `중앙 34일`)과 상시채용 비율(예: `상시 21.5%`)을 뱃지 두 개로 제공.
*   **문구 규칙:** **모집 기간**으로만 서술한다. 원천이 게시한 계획된 마감일이므로 "충원 난이도"나 "자리가 비어 있다"로 해석하지 않는다 ([기능 명세 §4.5·US-D5](functional-specification.md)).
*   **표본 부족:** 마감일 보유 표본이 기준 미달이면 수치 자리에 `표본 부족`을 두고 상시채용 비율 뱃지만 남긴다.

### 3.2 분리된 화면 (추이분석 / 시뮬레이터 / 마이페이지)

*   **추이분석 (`/dashboard/trends`):** 기존 대시보드 하단에 있던 `[Tab: 소득vs물가 / 스킬수요 / 연봉분포]` 블록이 그대로 이동. 컴포넌트 상세는 §4 참고.
*   **시뮬레이터 (`/dashboard/simulator`):** 기존 12개월 시뮬레이터 카드가 카드 폭에서 화면 폭으로 확장되어 이동.
*   **마이페이지 (`/mypage/records`, `/mypage/profile`):** 기록관리(연봉·소비·스킬 이력)와 계정설정(세션·삭제)을 내부 탭 2개로 통합.

## 4. 데이터 시각화 컴포넌트

이 컴포넌트들은 추이분석(`/dashboard/trends`) 화면에 위치합니다.

### 4.1 소득 vs 물가 추세선 (Line Chart)
*   **X축:** 월별 시간 흐름 (최근 12개월)
*   **Y축:** 지수 (기준월 = 100). 원화 금액과 지수를 같은 축에 겹치지 않는다.
*   **차트 요소:**
    *   **실선 A (Indigo):** 소득 지수 (`incomeIndex`, 기준월 100)
    *   **점선 B (Amber):** 개인물가 지수 (`personalPriceIndex`, 기준월 100)
    *   **음영 영역:** A 곡선이 B 곡선 아래로 내려갈 때(= 구매력 지수 < 100), 두 선 사이의 틈을 희미한 빨간색 그라데이션 음영으로 칠해 **'구매력 손실'** 구간임을 직관적으로 인지시킴.
    *   원화 금액(명목 실수령액)은 툴팁에서만 보조 정보로 표시.

### 4.2 동료집단 연봉 분포 막대 (Range Bar / Box Plot)
*   **디자인:** 가로 선으로 된 스펙트럼 바 위에 최소값, 25%, 중앙값(50%), 75%, 최대값을 도식화.
*   **사용자 핀:** 가로 바 상단에 현재 사용자의 연봉을 나타내는 세로 핀(Pin) 지시선과 사용자 프로필 말풍선 노출.
    *   *예: "내 연봉은 동료집단 중 상위 65% 위치에 있습니다."*
